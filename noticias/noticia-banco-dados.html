Do papel ao MySQL: modelando o primeiro banco de dados

Entidades, relacionamentos e as primeiras tabelas.

Antes de escrever qualquer comando SQL, desenhamos no papel as entidades do sistema e como elas se relacionam. Esse modelo conceitual evita retrabalho e deixa claro o que cada tabela precisa armazenar.

Em seguida, transformamos o modelo em tabelas no MySQL, definindo chaves primárias, chaves estrangeiras e os tipos de dados mais adequados para cada coluna. Um INT para identificadores, VARCHAR para textos curtos e DATE para datas.

Com as tabelas prontas, inserimos alguns registros de teste e escrevemos consultas simples com SELECT para conferir se os relacionamentos estavam corretos.

O aprendizado principal foi perceber que a modelagem é uma etapa de planejamento: quanto melhor o desenho, mais simples fica manter e evoluir a aplicação no futuro.
